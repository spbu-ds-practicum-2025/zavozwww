# План E2E Тестирования проекта FilmBuddy

Этот документ описывает сценарии сквозного (End-to-End) тестирования для демонстрации функциональности проекта FilmBuddy. Тесты покрывают основные пользовательские пути: регистрацию, управление профилем, социальное взаимодействие и систему рекомендаций.

## Окружение
- **Base URL (Gateway):** `http://localhost`
- **Auth Service:** `/filmbuddy`
- **Social Service:** `/social`
- **Rec System:** `/recsys`

---

## Сценарий 1: Регистрация и Аутентификация (User Onboarding)

**Цель:** Проверить возможность создания нового пользователя и входа в систему.

1.  **Регистрация пользователя**
    *   **Endpoint:** `POST /filmbuddy/register`
    *   **Действие:** Отправка данных нового пользователя (username, email, password).
    *   **Ожидаемый результат:** `201 Created`, сообщение об отправке кода подтверждения.

2.  **Подтверждение почты**
    *   **Endpoint:** `POST /filmbuddy/verify`
    *   **Действие:** Отправка email и кода подтверждения (из Mailpit/логов).
    *   **Ожидаемый результат:** `200 OK`, токены доступа (access_token, refresh_token).

3.  **Вход в систему (Login)**
    *   **Endpoint:** `POST /filmbuddy/login`
    *   **Действие:** Вход с зарегистрированными email и паролем.
    *   **Ожидаемый результат:** `200 OK`, получение новых токенов.

4.  **Обновление токена (Refresh)**
    *   **Endpoint:** `POST /filmbuddy/refresh`
    *   **Действие:** Отправка refresh_token.
    *   **Ожидаемый результат:** `200 OK`, новая пара токенов.

---

## Сценарий 2: Управление Профилем

**Цель:** Проверить возможность просмотра и редактирования данных пользователя.

1.  **Получение своего профиля (Auth)**
    *   **Endpoint:** `GET /filmbuddy/profile`
    *   **Действие:** Запрос профиля с валидным токеном.
    *   **Ожидаемый результат:** `200 OK`, JSON с данными пользователя (ID, email, username).

2.  **Заполнение/Обновление профиля**
    *   **Endpoint:** `POST /filmbuddy/profile`
    *   **Действие:** Отправка дополнительных данных (имя, фамилия, аватар).
    *   **Ожидаемый результат:** `200 OK`, профиль обновлен.
---

## Сценарий 3: Социальное Взаимодействие (Social Graph)

**Цель:** Проверить механику добавления в друзья между двумя пользователями (User A и User B).

1.  **Поиск пользователя**
    *   **Endpoint:** `POST /filmbuddy/friends/searchFriends`
    *   **Действие:** User A ищет User B по имени (username).
    *   **Ожидаемый результат:** `200 OK`, список найденных пользователей.

2.  **Отправка заявки в друзья**
    *   **Endpoint:** `POST /social/friends/requests`
    *   **Действие:** User A отправляет заявку User B.
    *   **Ожидаемый результат:** `200 OK`, сообщение "friend request sent".

3.  **Просмотр входящих заявок (User B)**
    *   **Endpoint:** `GET /social/friends/requests`
    *   **Действие:** User B запрашивает список заявок.
    *   **Ожидаемый результат:** `200 OK`, в списке есть заявка от User A.

4.  **Принятие заявки (User B)**
    *   **Endpoint:** `POST /social/friends/requests/accept`
    *   **Действие:** User B принимает заявку от User A.
    *   **Ожидаемый результат:** `200 OK`, заявка принята.

5.  **Проверка списка друзей**
    *   **Endpoint:** `GET /social/friends`
    *   **Действие:** Оба пользователя запрашивают свои списки друзей.
    *   **Ожидаемый результат:** `200 OK`, друг отображается в списке у обоих.

6.  **Отклонение заявки в друзья (Альтернативный сценарий)**
    *   **Endpoint:** `POST /social/friends/requests/reject`
    *   **Действие:** User B отклоняет входящую заявку (предварительно создав новую).
    *   **Ожидаемый результат:** `200 OK`, сообщение "friend request rejected".

## Сценарий 4: Фильмы и Рекомендации

**Цель:** Проверить интеграцию с системой рекомендаций и сохранение оценок.

1.  **Поиск фильмов**
    *   **Endpoint:** `POST /recsys/search`
    *   **Действие:** Поиск фильма по названию или жанру.
    *   **Ожидаемый результат:** `200 OK`, список фильмов, соответствующих запросу.

2.  **Оценка фильма**
    *   **Endpoint:** `POST /social/ratings`
    *   **Действие:** Пользователь ставит оценку (1-5) и пишет отзыв к фильму.
    *   **Ожидаемый результат:** `201 Created`, оценка сохранена.

3.  **Просмотр своих оценок**
    *   **Endpoint:** `GET /social/ratings`
    *   **Действие:** Запрос списка оцененных фильмов.
    *   **Ожидаемый результат:** `200 OK`, список содержит только что добавленную оценку.

4.  **Получение рекомендаций**
    *   **Endpoint:** `GET /social/recommendations`
    *   **Действие:** Запрос персональных рекомендаций.
    *   **Ожидаемый результат:** `200 OK`, список фильмов, подобранных на основе поставленных оценок (Collaborative Filtering).

---

## Сценарий 5: Завершение сессии

1.  **Выход из системы**
    *   **Endpoint:** `POST /filmbuddy/logout`
    *   **Действие:** Отправка запроса на выход.
    *   **Ожидаемый результат:** `200 OK`, токены аннулированы.
